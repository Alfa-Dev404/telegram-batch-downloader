# Security policy

## Reporting a problem

Please report security problems **privately** through
[GitHub's private vulnerability reporting](https://github.com/Alfa-Dev404/telegram-batch-downloader/security/advisories/new),
not in a public issue.

Include what an attacker could do, the steps to reproduce it, and the script version. You'll get a reply within a week.

## What counts

-   A file name, caption or message from Telegram that makes the script write outside the chosen folder, run code, or
    break the page.
-   Anything that sends data anywhere other than Telegram, or exposes account details, chat names or file names in places
    the README says are safe to share (such as "Copy debug info").
-   Ways for a web page or another script to drive the downloader or reach the folder it was given.

## Supported versions

Only the latest release gets fixes. Tampermonkey updates the script automatically from this repository.
